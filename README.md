# 🍉 Slice & Spite 💣

A two-player couples game: **Fruit Ninja × Bloons TD Battles**.

One of you is the **Slicer** — classic fruit-slicing, swipe to cut, don't hit bombs
(3 hearts, lose them all and your round ends). The other is the **Saboteur** — you
earn coins over time (BTD-Battles style eco) and spend them to sabotage:

| Weapon | Cost | What it does |
|---|---|---|
| 💣 Bomb | $30 | Thrown where you aim — sliced = the Slicer loses a heart (you get a $15 bounty) |
| 🎆 Cluster | $75 | 3 bombs + 3 fruit volley, mixed together |
| 🍉 Trap | $45 | Looks like a watermelon, costs 50 points when sliced (it sparkles purple if you look closely…) |
| 🍒 Flood | $25 | 6 fruit burst — chaos cover for your bombs (missed fruit cost the Slicer points) |
| 🌫️ Smoke | $35 | Fogs the Slicer's screen for a few seconds |
| 📈 Eco | $60 | +$4/s income for the rest of the round (stacks ×3) |

90 seconds per round, then you **swap roles**. Highest slicing score wins. 👑

## Play modes

- **Two Phones** — real-time online play over WebRTC (PeerJS public cloud for
  matchmaking, then peer-to-peer). Host gets a 4-letter room code.
- **One Device** — couch mode: the Slicer swipes the arena while the Saboteur
  uses the control deck + aim strip at the bottom. Great on an iPad.

Works in iOS Safari — for the best experience use **Share → Add to Home Screen**
to get it fullscreen like a real app.

## Run locally

```bash
node tools/serve.mjs
```

then open http://localhost:8123. Plain static files — no build step, no dependencies
(PeerJS is loaded from cdnjs).

## Deploy (GitHub Pages)

1. Create an empty **public** repo on github.com (e.g. `slice-and-spite`).
2. From this folder:
   ```bash
   git remote add origin https://github.com/<you>/slice-and-spite.git
   git push -u origin main
   ```
3. On GitHub: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
4. Your game is live at `https://<you>.github.io/slice-and-spite/` — open it on
   both phones, one hosts, the other joins with the code.

Any static host works (Netlify, Vercel, Cloudflare Pages) — there is no server code.

## Tech notes

- All game physics are closed-form ballistics, so the Saboteur's mirror view
  replays the Slicer's arena exactly from spawn events alone — no position
  streaming, no drift, tiny bandwidth.
- The Slicer's device is authoritative for scoring; the Saboteur's device is
  authoritative for its own coins. Icons are generated by `tools/make-icons.mjs`
  (hand-encoded PNG, zero deps).
